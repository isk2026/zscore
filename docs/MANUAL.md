# 주도주 퀀트 스코어 — 사용 설명서

> 대시보드: **https://isk2026.github.io/zscore/**
> 성상현 「매크로비욘드」 12부 프레임워크 — *주도주는 규칙으로 고르고, 위험은 규칙으로 담으며, 성과는 규칙으로 검증한다.*
> 개인 투자 참고용이며 투자 권유가 아닙니다. 화면의 모든 "신호"는 규칙상 결과일 뿐 매수·매도 추천이 아닙니다.

## 2. 추천 사용 루틴

**매일 (알림 받았을 때, 1~2분)**
1. 텔레그램 알림 확인 — Tier 1 진입/이탈, 새 위험 경고, 시장폭 괴리, 섹터 사분면 이동
2. 보유 종목이 언급됐으면 **분석** 탭에서 "왜 이 등급인가" 와 위험 경고 확인

**매주 (10분)**
1. 상단 국면 · **시장** 탭: 200일선 위 종목 비율(강함/중립/약함), 시장폭 괴리, 주도 사분면 섹터
2. **스크리너**: Tier 1 중 심각 경고 없는 종목, 수급 ▲/▼
3. 관심 종목 2~4개를 **비교**

**매월 (리밸런싱, 30분)**
1. **울타리** 탭 → 모델 포트폴리오 확인 → 미국/한국 배분 비율 정하고 "불러오기"
2. 실제 보유와 다르게 조정한 뒤 위반(빨간 상자)이 없는지, **포트폴리오 위험**(숨은 집중·유효 베팅 수·과거 하락 구간)을 확인
3. **백테스트** 탭 실전 기록에서 모델이 동일가중·지수 대비 어떻게 가고 있는지 확인

## 3. 화면별 사용법

### 상단 바
- **검색**: 종목명·티커·한국 6자리 코드 (`NVDA`, `삼성전자`, `005930`)
- **미국/한국** 전환, **갱신**(최신 데이터 다시 읽기)
- 국면 표시: `🇺🇸 국면 1 상승 따라가기 · 주식 78%` — Beta Model 이 정한 다음 거래일 주식 비중
- 데이터가 72시간 넘게 갱신되지 않으면 노란 경고가 뜹니다 (자동 갱신 실패 신호)

### 분석 탭
- **Tier 배지**: T1 핵심(최우선) · T2 펀더멘털(추세 회복 대기) · T3 모멘텀(추세 꺾이면 먼저 축소) · T4 관찰
- **왜 Tier N?** 한 줄 요약 — 강점과 실패한 축의 가장 약한 지표를 바스켓 순위로 보여줍니다.
  아래 작은 글씨는 실제 규칙 숫자(예: `종합 4.74 ≥ 3.0 · 모멘텀 2.02 < 3.0`)
- **등급 이력 막대**: 기준일별 Tier 색 (자동 갱신마다 쌓임)
- **데이터 신뢰도**: 지표 n/전체 · 최근 결산월 · 가격 기준일 · 수집 시각. 노란 경고가 있으면 점수를 덜 믿으세요
- **점수 카드**: 종합(펀더멘털)·모멘텀(1~5, 3.0 = 바스켓 평균) · Piotroski F(0~9) · Altman Z
- **수급**: 한국 = 최근 20거래일 외국인·기관·개인 순매수, 외국인 보유율 변화 / 미국 = 공매도 비중·변화·상환 일수.
  *모멘텀은 높은데 외국인·기관이 동반 순매도* 면 추세의 질을 의심
- **위험 필터**: 가치 함정 · 모멘텀 크러시 · 테마 과열 · 부실 · 저유동성 · 200일선 이탈
- **6-팩터 레이더 · 가격 차트 · 팩터 분해 · F/Altman 체크리스트**
- **＋ 비교에 추가**: 최대 4종목 → 스크리너 탭 맨 위에 비교 표

### 시장 탭
- **시장폭 카드**: 200일선 위 · 50일선 위 · 52주 고점 5% 이내 종목 비율, Tier 1 종목 수
  - 200일선 위 ≥60% 강함 · 40~60% 중립 · <40% 약함
- **시장폭 괴리**(주황 배너): 지수는 52주 고점 근처인데 50일선 위 종목이 3개월 고점보다 15%p 이상 줄어든 상태 — 소수 종목 장세, 상승 후반의 흔한 경고
- **섹터 주도력 지도**: 오른쪽 위 **주도** → 오른쪽 아래 **약화** → 왼쪽 아래 **소외** → 왼쪽 위 **개선** 순으로 시계 방향으로 돕니다. 큰 점이 최근 주, 선이 지난 8주 경로. 섹터/클러스터 전환
- **섹터 표**: Tier 1 비율 · 평균 점수 · **EPS 상향**(이익 추정치가 오른 종목 비율) · 3개월 수익 · 고점 근접 · 200일선 위. 행을 누르면 소속 종목
- ⚠ 시장 전체가 아니라 대형주 바스켓(미국 64 / 한국 44) 기준입니다

### 스크리너 탭
- **종목 비교**(비교 목록이 있을 때) — 레이더 겹치기 + 지표 표 + 각 종목의 등급 이유
- **최근 등급 변화** — 직전 기준일 대비 Tier 1 진입/이탈 · 상향/하향 · 새 위험 경고
- **4-Tier 매트릭스** — 가로 종합, 세로 모멘텀. 점을 누르면 분석으로
- **표** — 열 제목을 눌러 정렬, ＋ 로 비교 담기, **수급** 열 ▲(동반 순매수·공매도 감소) ▼(동반 순매도·공매도 과다/급증)
- Tier 버튼으로 필터, "심각 경고 종목 숨기기"

### 울타리 탭
1. **모델 포트폴리오** — Beta Model 주식 비중 × 국면별 Tier 예산 × 상위 종목, 울타리 상한으로 깎은 결과
   - 국면별 Tier 예산(T1/T2/T3): 상승 따라가기 70/15/15 · 미리 줄이기 75/25/0 · 하락 방어 60/40/0 · 공포 50/50/0
   - 심각 경고 종목은 Tier 1 이어도 제외, 깎인 몫은 현금
   - 미국/한국 슬라이더 → **불러오기** 로 아래 보유 표에 채움
2. **보유 종목 점검** — 비중(%)을 입력하면 종목·섹터·클러스터·Tier 상한 위반을 빨간색으로 표시, 규칙 적용 제안 비중 제공. 상한 값은 오른쪽에서 조정 가능
3. **포트폴리오 위험** — 실제 주가 움직임(2년 주간) 기준
   - 예상 연 변동성 · 2년 최대 낙폭 · S&P500/KOSPI 베타 · **유효 베팅 수** · 달러 노출
   - **숨은 집중**: 업종이 달라도 같이 움직이는 묶음(평균 상관 ≥0.6)과 묶음의 위험 기여. 위험 기여가 비중보다 크게 높으면 노란색
   - 종목별 비중 vs 위험 기여, 상관 지도
   - **과거 하락 구간 재현**: 2022 금리 인상 하락장 · 2024-08 엔캐리 청산 · 2025-04 관세 충격 · 최근 1년 지수 최대 낙폭
   - **원화 기준 / 현지통화** 전환 — 원화 기준은 미국 종목에 원/달러 변동을 반영
- 보유 비중은 **이 브라우저에만** 저장됩니다 (서버로 가지 않음). 기기를 바꾸면 다시 입력

### 백테스트 탭
- **실전 기록** — 첫 자동 실행일부터 모델 포트폴리오 · Tier 1 동일가중 · 유니버스 동일가중 · 지수를 매 기준일 평가, 매월 첫 기준일 리밸런싱. 생존 편향이 없는 유일한 검증 — 6~12개월 쌓인 뒤 판단
- **월간 백테스트** — 과거 월말마다 그 시점 정보로 재채점한 Tier 별 성과 · IC · 회전율. **생존 편향**이 있어 절대 수익보다 *동일가중 대비* 로 보세요
- **팩터 성과 모니터** — 6개 팩터의 최근 3·6개월 IC 와 월별 색 띠. "요즘 시장이 무엇에 보상하나"의 단서 (가중치 변경 근거로 쓰지 않음)

## 4. 점수 읽는 법

| 점수 | 뜻 |
|---|---|
| 3.0 | 비교 바스켓 평균 |
| 3.5 | 대략 상위 30% |
| 4.0 | 대략 상위 16% |
| 5.0 | 상한 (상위 2% 이상) |

- **종합** = 현금흐름 25 · 성장 25 · 수익성 20 · 재무안정 20 · 밸류 10
- **모멘텀** = 12-1M 수익률 35 · 52주 고점 근접 25 · 6M 상대강도 15 · EPS 추정치 30일 변화 25
- **Tier**: T1 종합≥3.0 & 모멘텀≥3.0 · T2 종합≥3.0 · T3 모멘텀≥3.5 · T4 나머지
- 점수는 같은 시장 바스켓 안의 **상대** 점수입니다. 미국 4.0 과 한국 4.0 을 직접 비교하지 마세요
- 금융업은 Altman Z 와 일부 현금흐름·부채 지표를 쓰지 않습니다

## 5. 텔레그램 알림 (Beta Model 봇)

자동 갱신(평일 16:40 · 07:20 KST) 후 **변화가 있을 때만** 옵니다. 같은 기준일은 한 번만.

| 항목 | 의미 |
|---|---|
| 🟢 Tier 1 진입 / 🔻 Tier 1 이탈 | 핵심 주도주 목록 변화 |
| ⬆️ 등급 상향 / ⬇️ 등급 하향 | T2↔T3↔T4 이동 |
| ⚠️ 새 위험 경고 | 모멘텀 크러시 · 테마 과열 · 부실 위험 신규 발생 |
| 🌐 시장폭 · 섹터 | 시장폭 괴리 발생/해소, 강함·중립·약함 전환, 섹터 사분면 이동(주 1회) |
| 📒 실전 기록 리밸런싱 | 매월 첫 기준일 모델 포트폴리오 교체 |

알림이 안 오면: GitHub → Settings → Secrets 에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 가 있는지, Actions 실행 로그의 "Telegram alert" 단계를 확인.

## 6. 휴대폰에서

- 브라우저로 대시보드 열기 → 공유 → **홈 화면에 추가** (앱처럼 열림)
- **종목 추가 채점 / 즉시 재채점**: 상단 ▷(실행) → GitHub *Run workflow* 펼치기 → `tickers` 에 `ASML, TSM, 000100` 처럼 입력(비우면 재채점만) → *Run workflow* → 3~5분 뒤 **갱신**
  - 추가 종목은 이후 매일 함께 갱신됩니다. 빼려면 `remove` 칸에 입력
  - 추가 종목은 바스켓 통계에 영향을 주지 않고 같은 기준으로 채점되며, 스크리너 매트릭스에는 안 나오고 검색·울타리에서 조회됩니다
- 저장소 주인(GitHub 로그인)만 실행할 수 있습니다

## 7. 자주 묻는 질문

**Q. 삼성전자가 Tier 1 인데 모델 포트폴리오에 없어요.**
심각 경고(예: 모멘텀 크러시 — 3개월 낙폭 −30% 이상)가 있으면 Tier 1 이어도 제외합니다. 울타리 탭 모델 포트폴리오 아래 "심각 경고로 제외" 목록에 이유가 있습니다.

**Q. 점수가 갑자기 바뀌었어요.**
연간 재무가 새로 반영됐거나(데이터 신뢰도의 결산월 확인), 바스켓의 다른 종목이 바뀌어 상대 위치가 변했을 수 있습니다. 등급 이력 막대로 언제 바뀌었는지 보세요.

**Q. 실전 기록이 지수보다 나빠요.**
몇 달은 운의 영향이 큽니다. 최소 6~12개월, 지수보다 *유니버스 동일가중* 대비로 판단하세요.

**Q. 수급이 '–' 로 나와요.**
한국은 네이버 증권, 미국은 yfinance 공매도 정보를 씁니다. 출처에서 받지 못하면 비워 두고 나머지 채점은 그대로 진행합니다.

**Q. 데이터가 며칠 전 것이에요.**
GitHub 예약 실행은 수십 분~수 시간 늦을 수 있고, 주말·휴일에는 새 종가가 없습니다. 72시간이 넘으면 상단에 경고가 뜨며, 그때는 ▷ 실행으로 수동 갱신하거나 Actions 로그를 확인하세요.

## 8. 한계

- 수급·시장폭·섹터 지도·위험 분석은 **표시 전용**이며 점수에 반영하지 않습니다
- 투자 판단과 책임은 본인에게 있습니다
